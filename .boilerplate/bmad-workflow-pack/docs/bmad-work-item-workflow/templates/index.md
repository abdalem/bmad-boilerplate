# Work Item Templates

Choose the configured type by semantic role:

| Role | Template |
| --- | --- |
| Long-lived product area | [Module](./module.md) |
| Demand requiring qualification | [Request](./request.md) |
| Cohesive business or user capability | [Feature](./feature.md) |
| Independently deliverable change | [Issue](./issue.md) |
| Incorrect existing behavior | [Bug](./bug.md) |
| Time-boxed investigation | [Spike](./spike.md) |

Fill only material fields. Do not invent product decisions or developer-owned implementation details. Every emitted item includes a delivery route, next action, and first next prompt.
