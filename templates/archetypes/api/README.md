# __PROJECT_NAME__ API

AdonisJS API baseline for product backends.

## Starter Endpoints

- `GET /health`
- `GET /api/v1/resources`
- `POST /api/v1/resources`

## Local run

```bash
cp .env.example .env
pnpm dev
```

In a monorepo, run it from the repo root with:

```bash
pnpm --dir apps/api dev
```
