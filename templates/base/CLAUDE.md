# Claude Code Guidance

Use `bmad-start-project` for an unconfigured boilerplate clone and
`bmad-update-project` before adopting or modernizing an existing repository.
Start actionable Feature, Issue, or Bug work with `bmad-build`, then
`bmad-close-work-item`. Use `bmad-publish-work-item` to create or refine unclear
items; a local work-item.md is optional for Build. Use `bmad-workflow-setup` only for onboarding or
explicit reconfiguration.

Use `docs/bmad-project-workflow/` for repository-level scenarios,
`docs/stack/` for stack-specific conventions, and
`docs/bmad-work-item-workflow/` for adaptive delivery. Use `bmad-build` for
implementation and never commit automatically.
